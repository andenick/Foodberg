# Foodberg - Output Deliverables

This directory contains all user-facing deliverables and reports generated by Foodberg.

## 📁 Directory Structure

### Data/
Excel files with commodity prices, recipe costs, and vendor comparisons.
**Important**: All Excel files follow Druck standard - **ONE SHEET PER FILE**.

- `current_commodity_prices.xlsx` - Latest terminal market prices
- `vendor_price_comparison.xlsx` - Multi-vendor price analysis  
- `recipe_costs_summary.xlsx` - Calculated recipe costs
- `menu_engineering_analysis.xlsx` - Menu profitability matrix
- `price_alerts_history.xlsx` - Alert log and statistics
- `weekly_market_report.xlsx` - Weekly summary data

### PDFs/
Professional LaTeX-generated reports for presentations and analysis.

- `foodberg_methodology_report.pdf` - Technical approach and data sources
- `market_analysis_report.pdf` - Current trends and predictions
- `executive_summary.pdf` - High-level overview for stakeholders
- `user_guide.pdf` - Platform usage instructions

### Charts/
Visual data exports and infographics.

- Price trend charts
- Menu engineering matrices
- Vendor comparison visualizations

### Documentation/
Additional documentation and guides.

- User manuals
- API integration guides
- Case studies

## 🎯 Usage

### For Chefs
1. Open `Data/` folder for Excel files
2. Use Excel to analyze pricing trends
3. Review PDFs in `PDFs/` for comprehensive reports

### For Management
1. Review `executive_summary.pdf` for business insights
2. Check `menu_engineering_analysis.xlsx` for profitability
3. Use charts for presentations

## 📊 Report Generation

Reports are automatically generated through the Foodberg dashboard:
1. Navigate to Reports Center
2. Select report type
3. Click "Generate"
4. Download from this directory

## 🔄 Update Frequency

- **Price Data**: Real-time (cached 1 hour)
- **Reports**: Generated on-demand
- **Historical Data**: Daily aggregation
